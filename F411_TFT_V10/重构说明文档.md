# STM32F411 智能家居环境监测系统 重构说明文档

## 重构日期

2026-05-22

## 重构目标

将原阻塞式主循环重构为基于 **10ms 系统节拍** 的 **状态机 + 分时任务调度** 架构，保证 TFT 刷新、按键、传感器、ESP8266、日志输出等任务互不阻塞。

## 二、架构对比

### 改造前（阻塞式）

```
main() → while(1) {
    读按键 → 画界面
    if (温湿度页面) {
        DHT11阻塞读取(~20ms)
        DS18B20阻塞读取(HAL_Delay 750ms)  ← 最严重
        ADC阻塞读取(HAL_ADC_PollForConversion × 3)
        MQTT阻塞上传(printf → HAL_UART_Transmit MAX_DELAY)
    }
    HAL_Delay(10);  ← 每轮固定等待
}
```

### 改造后（状态机分时调度）

```
main() → while(1) {
    App_Tick_Update();   // 软件10ms节拍
    App_Scheduler_Run(); // 分时调度9个任务
}

App_Scheduler_Run():
    TFT刷新      20ms/次
    按键扫描     10ms/次
    UI状态机     10ms/次
    ESP8266状态机 10ms/次
    UART日志     10ms/次
    蜂鸣器       10ms/次
    ADC采集      100ms/次
    DS18B20状态机 1s/次
    DHT11读取    2s/次
    MQTT上传     2s/次
```

## 三、10ms 系统节拍

### 实现方式

**软件节拍**：使用 `HAL_GetTick()`（SysTick 1ms 基准），每 10ms 递增 `g_tick_10ms`。

```c
/* app_scheduler.c */
volatile uint32_t g_tick_10ms = 0;  // 在 app_data.c 中定义

static void App_Tick_Update(void)
{
    static uint32_t last_ms = 0;
    uint32_t now_ms = HAL_GetTick();
    if (now_ms - last_ms >= 10) {
        last_ms += 10;
        g_tick_10ms++;
    }
}
```

### 为什么不用硬件TIM

TIM11（20ms周期）保留用于 `key_scan()` 硬件按键消抖。不改 CubeMX 初始化代码，确保可重新生成。

## 四、各模块改造详情

### 1. DS18B20 — 阻塞→非阻塞状态机（核心改造）

**改造前**：`ds18b20_getTemp()` 调用 `HAL_Delay(750)` 阻塞等待温度转换。

**改造后**：状态机分步执行，不阻塞其他任务。

```
状态转换:
  IDLE → START_CONVERT → WAIT_CONVERT(750ms) → READ_SCRATCHPAD → PROCESS_DATA → IDLE

调度周期: 100 tick (1s)，总循环约2秒完成一次读数
```

关键代码 (`app_tasks.c`):
```c
void DS18B20_Task(void)
{
    switch (ds18b20_state) {
    case DS18B20_STATE_IDLE:
        DS18B20_StartConvert();           // OneWire: init + SkipROM + Convert T
        ds18b20_convert_start_tick = g_tick_10ms;
        ds18b20_state = DS18B20_STATE_WAIT_CONVERT;
        break;
    case DS18B20_STATE_WAIT_CONVERT:
        if (g_tick_10ms - ds18b20_convert_start_tick >= 75) {  // 750ms非阻塞等待
            DS18B20_ReadScratchpad(&ds18b20_lsb, &ds18b20_msb);
            // 转到立即数据处理
        }
        break;
    // ...
    }
}
```

### 2. ESP8266 / MQTT — 阻塞AT指令→状态机

**改造前**：`Send_AT_Commands_Simple()` 串行发送9条AT指令，每条后 `HAL_Delay(500~5000ms)`，总计**阻塞约12秒**。

**改造后**：状态机逐步发送，用 `g_tick_10ms` 超时替代 `HAL_Delay`。

```
状态链:
  POWER_ON → AT_TEST(0.5s) → ECHO_OFF(1s) → SET_WIFI_MODE(0.5s)
  → CONNECT_WIFI(5s) → CONNECT_MQTT(5s) → MQTT_READY(2s) → MQTT_PUBLISH → IDLE
```

- 每 10ms 调用一次 `ESP8266_Poll_Task()`
- AT 指令通过 `printf` 写入日志 FIFO，异步发送到 ESP8266
- MQTT 上传由 `MQTT_Task()` 分时处理，每2秒发布一个 topic

### 3. TFT SPI DMA — 非阻塞刷新

**机制**：

1. `TFT_Update_Task()` 入口检查 `tft_spi_dma_busy`：DMA 忙则跳过本帧
2. TFT 绘图操作内部启动 DMA 传输
3. SPI1 DMA 发送完成后，`HAL_SPI_TxCpltCallback` 清除 `tft_spi_dma_busy`
4. SPI 频率保持 **50MHz**，DMA 配置不变

**刷新策略**：

- `ui_need_full_redraw`：页面切换时全屏重绘（最大值~24ms，仅按键触发）
- `ui_data_dirty`：传感器数据变化时**局部刷新**（~2ms）
- 无变化时 TFT 任务直接返回，零开销

### 4. UART 日志 — 阻塞发送→FIFO 异步

**改造前**：
```c
int fputc(int ch, FILE *f) {
    HAL_UART_Transmit(&huart1, &ch, 1, HAL_MAX_DELAY);  // 阻塞等待！
    return ch;
}
```

**改造后**：
```c
int fputc(int ch, FILE *f) {
    Log_WriteChar((char)ch);   // 写入FIFO，立即返回
    return ch;
}
```

- **1024 字节 FIFO** 环形缓冲区
- `UartLog_Flush_Task()` 每 10ms 发送一个字符（中断模式），不阻塞
- 支持 printf 异步输出

### 5. ADC 采集 — 阻塞轮询→定时任务

- `ADC_Task()` 每 100ms 执行一次
- 只在 `UI_PAGE_ADC` 页面时采集（省资源）
- `HAL_ADC_PollForConversion` 超时 10ms（原 100ms），快速超时返回

### 6. 按键 — 加入事件队列

- `key_scan()` 由 TIM11（20ms）硬件中断调用，消抖可靠
- `Key_Scan_Task()` 检测按键后推入事件队列
- `UI_Task()` 从队列取事件，驱动页面状态机

事件类型：
```c
typedef enum {
    KEY_EVENT_NONE = 0,
    KEY_EVENT_SHORT_PRESS,
    KEY_EVENT_LONG_PRESS
} Key_Event_Type_t;
```

### 7. UI / 菜单 — if-else堆→页面状态机

```
页面状态: HOME ↔ TEMP_HUMI / ADC / WIFI / SYSTEM_INFO

KEY1(确认): HOME → 进入选中页面
KEY2(返回): 任意页面 → HOME
KEY3(下):   HOME菜单选择下移，触发全屏重绘
KEY4(上):   HOME菜单选择上移，触发全屏重绘
```

- 菜单高亮选中项（红色）
- 页面切换全屏重绘
- 传感器数据变化仅局部刷新数值区域

### 8. 蜂鸣器 — 状态机控制

- `Buzzer_Task()` 每 10ms 检查激活标志
- `Buzzer_Beep(duration)` 启动蜂鸣，到期自动关闭
- 使用 PC13（板载LED，等效声光报警）

### 9. DHT11 — 保持原有驱动

- 每 2 秒调用一次 `DHT11_Read_Task()`
- 底层协议需微秒级时序（`delay_us`），保留原有实现
- 读取失败保留上次有效值，防止 TFT 显示跳变
